# Application Flow for AMI by Arham

## 1. Global Navigation
*   **Header:** Brand logo (centered), hidden menu toggle (hamburger) leading to "Our Story", "Contact", and "Admin Login".
*   **Floating Action:** A floating "Favorites" icon (visible only if items are swiped right) indicating the count of saved items.

## 2. User Journey: Landing & Storytelling
1.  **Entry:** User lands on the homepage.
2.  **Hero Section:** High-impact video/image background with the brand logo and a defining value proposition.
3.  **Scroll Interaction:** As the user scrolls, text and images fade in sequentially (following `design.md` pacing), explaining the lab-grown diamond and gold heritage.
4.  **Decision Node:** At the end of the story, the user is presented with two visual pathways:
    *   Path A: "Submit Your Vision"
    *   Path B: "Discover Inspiration"

## 3. User Journey: Path A - "Bring Your Own Idea"
1.  **Selection:** User clicks "Submit Your Vision".
2.  **Input View:** A clean modal or dedicated page opens.
3.  **Action:** User pastes a URL (IG/Pinterest) OR uploads a screenshot.
4.  **Refinement:** User types specific instructions into the "Design Notes" text area.
5.  **Lead Capture:** User inputs Name, WhatsApp number, and Email.
6.  **Completion:** User clicks "Request Quote". Success screen appears confirming the admin will reach out within 24 hours.

## 4. User Journey: Path B - "Swipe Engine"
1.  **Selection:** User clicks "Discover Inspiration".
2.  **Swipe View:** A full-screen card interface loads.
3.  **Interaction:** 
    *   Drag right: Card is marked "Saved", added to Favorites, and disappears.
    *   Drag left: Card is discarded.
4.  **Review:** User taps the floating "Favorites" icon.
5.  **Favorites Board:** A grid layout displays all saved images. User can tap 'X' to remove items.
6.  **Submission:** User taps "Request Quote for These", triggering the Lead Capture form (Name, WhatsApp, Email, Notes).
7.  **Completion:** Success screen appears.
